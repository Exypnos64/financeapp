# `.claude/notes/` — Disposable Session Scratch

This directory is for **temporary, non-authoritative** working notes during a session — rough
investigation logs, scratch reasoning, things-to-check lists.

**These notes are not a source of truth.** When something learned here is durable, **promote it**
into the right reference doc under `.claude/docs/` (or into `CLAUDE.md`'s index / a rule), and
then **delete the note**. A note that survives many sessions is a signal it should have become a
doc.

This `README.md` is the one permanent file here; everything else is expected to come and go.
